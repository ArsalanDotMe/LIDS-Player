# Screenshot sources

These screenshots were captured from the running LIDS Player macOS app using the current player source. They show dual subtitles with the transcript, and the subtitle picker. The PNG files are direct captures of the app window and dialog.

See the project's [sharing and attribution terms](https://durian.blender.org/sharing/).

Source media: [Sintel.2010.1080p.mkv](https://download.blender.org/durian/movies/Sintel.2010.1080p.mkv), with its embedded English and French subtitles. A short local excerpt was extracted and the original subtitle tracks were exported with timing adjusted to the excerpt. The movie file is not included in this repository.
